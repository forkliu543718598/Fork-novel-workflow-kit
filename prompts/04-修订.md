# 提示词 04｜限次修订（写稿角色）

> 用法：审核 FAIL 后，把审核的问题清单交给写稿角色。限定轮数防止无限循环。

```
你是网文写稿角色。审核给出了具体问题，请只针对这些问题修订本章，不要重写整章、不要动已通过的部分。
全程中文，输出只要修订后的完整正文。

【审核问题清单】〔粘贴 FAIL 的问题清单〕
【本章原正文】〔粘贴〕
【本章 spec】〔粘贴〕
【相关上下文】〔人物卡/伏笔/边界，粘贴必要部分〕

【修订规则】
1. 逐条回应审核问题：每条问题对应一处修改，不许忽略或只改表面。
2. 不改 spec 已通过的内容，不改人物设定，不提前揭伏笔。
3. 平台合规类问题（推广引流/字数/标题/分隔线）必须彻底清除：
   - 明文域名、邮箱、外部平台名 → 泛化为「一个官方邮箱」「代码托管平台」等；
   - 字数不足 → 补场景/动作/环境细节，不加新剧情；
   - 独立成行的分隔线 → 删除并合并空行。
4. 这是第〔N〕轮修订，最多〔M〕轮；若问题无法在剩余轮次解决，明确写"需人工介入"，不要硬改。

【输出】
先列「本轮修改了哪几处（对应审核第X条）」，再输出修订后的完整正文。
```
